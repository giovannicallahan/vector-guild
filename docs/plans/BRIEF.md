# Brief for plan authors

Write `docs/plans/<ID>-PLAN.md` for each pack you were given. Read first: `docs/CALC1-PLAN.md` (the format to follow exactly, section by section), `docs/plans/README.md` (what the player has finished before each pack), `docs/PACK-FORMAT.md` §2.3, §7 and §11, and two missions of `game/realms/calc1/missions-a.js` to see what a mission looks like. Write only your plan files; edit nothing else.

The game teaches adults with no maths background beyond the packs listed as finished. Each plan must contain:

1. **Header**: pack id, name, "40 learn + 120 practice = 160".
2. **Player**: exactly what the player knows, and the list of every new word and symbol the pack teaches (each is taught in the mission that first uses it).
3. **Setting**: the same Kepler outpost with Mira as mentor, at a new stage that suits the subject (one or two sentences, concrete places and objects).
4. **Sources**: one or two open textbooks whose sections are free web pages with stable URLs. Prefer OpenStax where a suitable book exists (Calculus Volume 2 and 3, Introductory Statistics 2e, University Physics Volume 1–3, Contemporary Mathematics). Otherwise an established open text (for example Judson, Abstract Algebra: Theory and Applications; Levin, Discrete Mathematics: An Open Introduction; Lebl, Basic Analysis and Notes on Diffy Qs; Beck et al., A First Course in Complex Analysis; Hammack, Book of Proof; Raji, An Introductory Course in Elementary Number Theory on LibreTexts; Morris, Topology Without Tears). **Open every section URL you cite with WebFetch and confirm the page exists and covers the concept. Never cite a URL you did not open. If a page cannot be opened, pick another source or mark the concept `UNVERIFIED` with the reason.** Give the URL pattern, the publisher word a source title will contain, and a table `concept → section title → URL`.
5. **Chapter table**: 7 chapters with ids q01–q06, q07–q11, q12–q17, q18–q23, q24–q29, q30–q34, q35–q40; tiers Basic, Basic, Intermediate, Intermediate, Intermediate, Advanced, Advanced (100, 100, 150, 150, 150, 200, 200 XP); for each chapter a name, a one-sentence blurb, a sector (a place in the outpost), the sector's purpose as a phrase that completes "we have to …", and a landmark name (a structure drawn on the ridge).
6. **Concepts**: 40 lines `qNN title [source section]`, in teaching order, each with one short line "Asked:" saying what number the player types. Chapters 2, 3, 4 and 5 end with a chapter review; q40 is a realm review and a bridge to the next pack. Each concept lists its one or two prerequisite missions.
7. **Answers**: every answer is a number (whole, decimal or fraction typed in one box, or several boxes). A formula, a word, a proof or a set is never an answer. For subjects that are not numeric by nature (logic, proof, topology, abstract algebra) say how each concept becomes a number: a truth value typed as 1 or 0, a count, an index of a step, an element of Z_n, an Euler characteristic, the smallest counterexample, and so on. Every concept must allow a generator that draws new numbers each time, so say what varies.
8. **Ranks**: nine rank titles in capitals, rising, the last one "MASTER OF …". **Achievements**: a name for learning all 40 concepts and a name for solving all 160. **Copy**: a home title in two short sentences, a first-visit welcome from Mira (2–3 sentences), the label of the first button, and an all-done line that names the next pack. **Must-have glossary terms**: 10–14 words the pack teaches.

Rules: plain English, no jargon before it is taught, British spelling as in the existing packs, radians for angles, SI units. Missions are original; never copy textbook problems. Keep each plan under 130 lines.

Report back: for each pack, the source books chosen, how many URLs you opened and how many are UNVERIFIED, and any concept you think is hard to ask as a number.

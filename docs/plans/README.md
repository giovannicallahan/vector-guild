# Realm plans

One plan per pack, `<ID>-PLAN.md`, in the format of `docs/CALC1-PLAN.md`. Every pack has the calc1 shape: 40 learn missions `q01`–`q40` in 7 chapters (6, 5, 6, 6, 6, 5, 6 concepts; tiers Basic, Basic, Intermediate, Intermediate, Intermediate, Advanced, Advanced) and 120 practice missions.

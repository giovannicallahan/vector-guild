# Calculus 1 pack (`calc1`) — concept plan

Pack id `calc1`, name "Calculus 1: change", 40 learn missions (`q01`–`q40`) + 120 practice (`qNNb/c/d`) = 160. Format: `docs/PACK-FORMAT.md` (every rule there applies; read "found" as "calc1").

**Player:** an adult who has finished Foundations (arithmetic, fractions, algebra, lines, quadratics, function notation, exponentials, logarithms, right-triangle and unit-circle trigonometry) and nothing more. Every calculus word and symbol (limit, lim, →, Δ, derivative, f′(x), dy/dx, tangent, ∫, antiderivative, e as a base when used with derivatives) is taught in the mission that first uses it. Radians are used for trigonometry; say so.

**Setting:** the Kepler outpost has grown: things now move and flow. Mira is still the mentor. Settings are rovers, shuttles, tanks, pumps, antennas, batteries, greenhouse growth.

**Sources:** OpenStax Calculus Volume 1 (`https://openstax.org/books/calculus-volume-1/pages/<section-slug>`), at least one per learn mission; open the page before setting `verified`. Missions are original, never copied.
